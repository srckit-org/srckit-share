# srckit-share

> Part of [srckit](https://github.com/srckit-org/srckit) — developer tools suite

Encode text as base64 and create shareable links. No server required.

## Features

- **Create** — Encode text to base64, generate shareable URLs with encoded content
- **Links** — Decode shared URLs or pasted base64 content

## Tech Stack

React 19 · MUI 9 · Tailwind CSS 4 · TypeScript 6 · Vite 8

## Getting Started

```bash
npm install
npm run dev
```
